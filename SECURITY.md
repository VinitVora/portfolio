# Security Policy

## Reporting a vulnerability

Please report security concerns affecting vinitvora.com privately to contact@vinitvora.com.

Include the affected URL, a concise description, safe reproduction steps and potential impact. Do not include real credentials, personal data, destructive payloads or public disclosure links.

Please do not test beyond what is necessary to identify the issue. Denial of service, social engineering, automated high-volume scanning and access to other users' data are not authorized.

This policy is a reporting channel, not a bug-bounty program or blanket authorization to test.

# vinitvora.com

Source code for Vinit Vora's professional application-security portfolio and consulting website.

## Stack

- React 18 and TypeScript
- Create React App
- styled-components
- React Router
- Netlify deployment and forms

## Local development

Requirements: a supported Node.js LTS release and npm.

```bash
npm ci
npm start
```

Production build:

```bash
npm run build
```

## Deployment

The repository build command is `npm run build`; the expected publish directory is `build`. The production branch and dashboard configuration must be verified in Netlify before they are documented as authoritative.

## Security and privacy

This repository must not contain employer/client confidential data, real vulnerability evidence, credentials, internal architecture or exploit-ready production details. Case studies are anonymized professional-experience summaries and are not presented as freelance-client engagements.

Please report security concerns privately to contact@vinitvora.com. Do not open a public issue containing vulnerability details.
